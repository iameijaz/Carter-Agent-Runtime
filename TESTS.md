## What each check guards

**scrub-check** — No personal or institutional identifier in any tracked file. This is the publish gate.

**turns-log** — Per-turn log round-trips every column. Drift here silently destroys the improvement curve.

**success-cache** — The bypass answers with no model, so nothing downstream can catch a wrong match. Asserts the misses: reversed word order, an added restriction, a flipped negation, any date-bearing argument, a write tool, a different tool schema. Plus that the offline summarizer ranks and dedupes.

**mistake-memory** — Failed tool calls are captured and recalled — the mechanism the project is built on.

**mistake-memory-stress** — Attacks the headline sentence itself: that EVERY failure is replayed into EVERY later turn. Covers single unfixed failures, cross-session fixes, id-varying errors, prefix collisions, concurrency and restart.

**config-guards** — Unconfigured mailbox and catalogue tools refuse before reaching the network.

**prompt-enrichment** — A recorded lesson reaches the next turn's system prompt. This is the README's headline claim, so it fails the build rather than quietly flattening.

**typecheck** — Whole tree typechecks.
